# 06-large

動画、PDF、画像、データセットなどGit管理に適さない大容量ファイルを置くためのローカル領域です。

このディレクトリのREADME、.gitignore、manifest.json以外の内容はGit管理対象外です。必要なファイルは削除・上書きに強い外部バックアップへ別途保存し、Gitには一覧やハッシュなどの軽量な管理情報だけを残します。

`manifest.json`には、`scripts/migrate_knowledge.py`が検出したバイナリの論理名、サイズ、SHA-256、外部保管先の論理パス、最終確認日を登録します。外部保管先の絶対パスや認証情報は保存しません。
