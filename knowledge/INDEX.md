# Knowledge Index

このディレクトリは、プロジェクトで再利用する知識・原本・成果物・定期記録を管理します。

## 読み取り順

1. `00-rules/`
2. 作業に関係する `02-facts/`
3. 必要に応じて `04-sources/`
4. 必要に応じて `03-output/`、`05-tasks/`

ナレッジ全体を一括で読み込まず、現在の作業に必要なファイルだけを選択してください。

## 分類

| 番号 | ディレクトリ  | 役割                                                      |
| ---- | ------------- | --------------------------------------------------------- |
| 00   | `00-rules/`   | 読み書き・分類・安全ルール                                |
| 01   | `01-private/` | Git管理しないローカル限定情報。秘密情報そのものは置かない |
| 02   | `02-facts/`   | 検証済みで現在有効な事実                                  |
| 03   | `03-output/`  | レポート・下書き・生成成果物                              |
| 04   | `04-sources/` | 原本、外部資料、会議記録、定期キャプチャ                  |
| 05   | `05-tasks/`   | 未整理タスク、進行中、保留中の作業                        |
| 06   | `06-large/`   | Git管理しない大容量ファイル                               |
| 99   | `99-archive/` | 通常参照から外した退避資料                                |

## 定期保存フロー

```text
作業・ログ・外部資料
        ↓
04-sources/04.01-periodic-captures/
        ↓ 整理・検証
02-facts/
        ↓ 必要に応じて生成
03-output/
```

定期キャプチャは日付付きで追記し、過去の原本を上書きしません。事実として残す内容は、検証後に `02-facts/` へ整理します。

## プロジェクト管理

プロジェクトの現在状態はリポジトリ直下の `PROJECT.md`、複数プロジェクトの一覧は `projects/`、要件・設計・実装タスクは各プロジェクトの仕様管理領域で管理します。
