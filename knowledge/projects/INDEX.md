# Projects Index

複数プロジェクトの現在状態を一覧するための索引です。このファイルは骨格で、実際のプロジェクトの行は、個人側のリポジトリにだけ書きます。

各プロジェクトの詳細は、そのプロジェクトのリポジトリの `PROJECT.md` を正本とします。ここには、概要、状態、次のアクション、リポジトリの論理IDだけを記録します。

## 書き方

- `name`: ASCIIのkebab-caseで、この表の中で一意にします。番号は付けません。
- 状態: 下の状態値のいずれかを書きます。
- リポジトリ: `owner/repo`、または認証情報を含まないリモートURLを書きます。まだない場合は `-` と書きます。ローカルの実パスは書きません。
- 最終確認日: `YYYY-MM-DD` で書きます。

## Status values

- `active`: 実行中
- `paused`: 一時停止
- `waiting`: 確認・承認待ち
- `completed`: 完了
- `archived`: 通常参照から除外
