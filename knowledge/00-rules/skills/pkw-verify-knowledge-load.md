# pkw-verify-knowledge-load

## 目的

ナレッジの移行後に、AIツールが入口から共有エージェントまで辿れているか、移行結果が一致しているかを確認します。確認だけを行い、ナレッジやファイルは変更しません。

## 手順

1. **入口**: 現在のセッションに、`AGENTS.md` の「作業開始時」の手順が読み込まれているかを確認します。ツールが読み込み済みのファイルを一覧できる場合は、その一覧も確認します（例: Claude Codeは `/memory`、Gemini CLIは `/memory show`）。
2. **索引とルール**: `knowledge/INDEX.md` と `knowledge/00-rules/` のルールを開けるかを確認します。
3. **共有エージェント**: `knowledge/00-rules/agents/pkw-knowledge-steward.md` を開けるか、このSkillが「Skill一覧」に載っているかを確認します。
4. **読み取りルールの遵守**: このセッションで開いたファイルを振り返り、次を満たしているかを確認します。
   - `knowledge/02-facts/` を一括で読んでいない
   - `knowledge/01-private/` を読んでいない
   - `knowledge/06-large/` を、必要がないのに読んでいない
5. **移行結果の照合**: `knowledge/04-sources/04.00-inbox/manifests/` にmanifestがある場合は、テンプレートリポジトリの `scripts/migrate_knowledge.py --verify` で照合できます。コマンドを実行できない環境では、この項目は「未確認」と報告し、利用者に実行を依頼します。

## 出力形式

項目ごとに、結果を次の4つのいずれかで報告します。

| 結果 | 意味 |
|---|---|
| 成功 | 確認できた |
| 警告 | 確認できたが、注意が必要 |
| 失敗 | 期待どおりではなかった |
| 未確認 | この環境では確認できなかった |

```text
| 項目 | 結果 | 根拠（相対パス、または確認した内容の要約） |
|---|---|---|
| 入口 | 成功 | AGENTS.md の作業開始時の手順 |
| 索引とルール | 成功 | knowledge/INDEX.md |
| 共有エージェント | 成功 | pkw-knowledge-steward |
| 読み取りルール | 成功 | 02-facts を一括で読んでいない |
| 移行結果の照合 | 未確認 | コマンドを実行できない環境 |
```

最後に、全体の結論を1行で示します。失敗が1件でもあれば、全体は「失敗」とします。

## 禁止事項

- ファイルの作成、更新、削除をしない。移行コマンドを `--apply` 付きで実行しない。
- 秘密情報、個人情報、絶対パス、ファイルの内容そのものを出力しない。根拠は相対パスか要約で示す。
- `knowledge/01-private/` を読まない。
- 確認できなかった項目を、成功と報告しない。
