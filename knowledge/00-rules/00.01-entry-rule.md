# 00.01 Entry Rule

## 目的

AIが作業開始時に必要な情報だけを、決められた順序で読むための入口ルールです。

## 手順

1. `AGENTS.md` を読む。
2. `PROJECT.md` で目的・状態・次のアクションを確認する。
3. `knowledge/INDEX.md` で分類を確認する。
4. `knowledge/00-rules/` の該当ルールだけを読む。
5. 現在の作業に直接関係する `knowledge/02-facts/` だけを読む。
6. 根拠確認が必要な場合だけ `knowledge/04-sources/` を読む。

## 禁止

- ナレッジ全体の一括読み込み
- 作業と無関係な事実の推測読み
- `01-private` の自動読み込み
- 原本を編集して事実として扱うこと
